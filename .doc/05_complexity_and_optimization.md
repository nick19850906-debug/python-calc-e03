# 05. $O(N^2)$ 시간 복잡도 및 메모리 최적화 이론

본 문서는 Mini NPU Simulator에서 수행되는 2차원 MAC 연산의 알고리즘적 시간 복잡도($O(N^2)$)를 수학적으로 증명하고, 1차원 Flattening을 통한 메모리 최적화 원리 및 하드웨어 NPU(시스톨릭 어레이)의 필요성을 설명합니다.

---

## 1. $O(N^2)$ 시간 복잡도의 수학적 유도

### 1.1 알고리즘 단계별 연산 횟수 분석
`calculate_mac_2d` 함수는 $N \times N$ 크기의 2차원 격자를 2중 중첩 반복문으로 순회합니다:

```python
for r in range(N):        # 바깥 루프: N회 반복 (r = 0 ~ N-1)
    for c in range(N):    # 안쪽 루프: N회 반복 (c = 0 ~ N-1)
        total_score += pattern[r][c] * filter_grid[r][c]  # 기본 연산 (곱셈 1회 + 덧셈 1회)
```

- 바깥쪽 루프가 1번 실행될 때마다 안쪽 루프는 정확히 $N$번 실행됩니다.
- 바깥쪽 루프가 총 $N$번 실행되므로, 안쪽의 기본 연산(곱셈 및 덧셈)이 실행되는 총 횟수 $T(N)$은 다음과 같습니다:

$$T(N) = \sum_{r=0}^{N-1} \sum_{c=0}^{N-1} 1 = \sum_{r=0}^{N-1} N = N \times N = N^2$$

- 따라서 점근적 표기법(Big-O)으로 나타내면 **$O(N^2)$** 시간 복잡도를 갖습니다.

## 2. 격자 크기 $N$ 증가에 따른 연산량의 2차 곡선형 폭발

한 변의 길이 $N$이 증가할 때 연산량($N^2$)은 선형이 아닌 **2차 곡선(Quadratic)** 형태로 가파르게 증가합니다:

```
연산 횟수 (Operations)
  ▲
10,000 │                                                   ● (100×100: 10,000회)
       │
 2,500 │                                     ● (50×50: 2,500회)
       │
   625 │                         ● (25×25: 625회)
   169 │             ● (13×13: 169회)
    25 │     ● (5×5: 25회)
     9 │ ● (3×3: 9회)
       └──────────────────────────────────────────────────────────► 격자 크기 (N)
         3   5       13          25          50            100
```

- $N=3 \rightarrow N=25$: 한 변의 길이는 **약 8.3배** 증가하지만, 연산 횟수는 **약 69.4배** 급증합니다.
- $N=3 \rightarrow N=100$: 한 변의 길이는 **약 33.3배** 증가하지만, 연산 횟수는 **약 1,111배** 폭발합니다.

## 3. 2D vs 1D Flattening 메모리 접근 최적화 분석

### 3.1 2D 리스트 인덱싱의 오버헤드 (`pat[r][c]`)
Python에서 2차원 리스트(`List[List[float]]`)는 실제 연속된 메모리 블록이 아니라 **"포인터의 리스트"** 구조를 가집니다.

```
[2D 리스트 메모리 구조 (불연속 포인터 체이닝)]
pat (외부 리스트) ──► [ Pointer Row 0 ] ──► [ float | float | float ] (Heap Chunk 1)
                  ──► [ Pointer Row 1 ] ──► [ float | float | float ] (Heap Chunk 2)
                  ──► [ Pointer Row 2 ] ──► [ float | float | float ] (Heap Chunk 3)
```

- `pat[r][c]`를 읽기 위해 CPU는:
  1. `pat` 객체에서 `r`번째 행 리스트의 포인터를 역참조(1차 Dereference).
  2. 찾아간 행 리스트에서 `c`번째 `float` 객체의 포인터를 다시 역참조(2차 Dereference).
- 메모리 공간이 분산되어 있어 CPU의 **L1/L2 캐시 미스(Cache Miss)**가 빈번히 발생합니다.

### 3.2 1D Flattening 선형 배열의 최적화 원리 (`pat[i]`)
2차원 배열을 1차원 리스트(`[val for row in grid for val in row]`)로 변환하면 단일 선형 버퍼가 구성됩니다:

```
[1D 리스트 메모리 구조 (연속 메모리 순차 탐색)]
pat_1d ──► [ float 0 | float 1 | float 2 | float 3 | float 4 | ... | float N^2-1 ]
```

- 단일 인덱스 `pat_1d[i]`로 바로 접근하므로 **포인터 역참조가 1단계로 축소**됩니다.
- CPU 캐시 컨트롤러의 **하드웨어 프리페처(Hardware Prefetcher)**가 다음 데이터를 미리 L1 캐시로 불러오는 **공간 지역성(Spatial Locality)**이 극대화됩니다.
- 실측 벤치마크 결과 동일한 $N^2$ 연산에 대해 1D 방식이 **약 1.5배 ~ 2.1배의 속도 향상(Speedup)**을 달성합니다.

## 4. 하드웨어 NPU(시스톨릭 어레이)와의 연계성

### 4.1 순차 CPU 처리의 한계
- 현대의 이미지 인식 AI 모델(예: ResNet, Vision Transformer)은 수천 개의 레이어에서 매 프레임마다 수십억 번($10^9$) 이상의 MAC 연산을 수행합니다.
- CPU의 순차적 2중 루프로는 실시간 처리가 불가능합니다.

### 4.2 NPU 시스톨릭 어레이(Systolic Array)의 혁신
NPU는 $N \times N$ 개의 초소형 곱셈-누적 하드웨어 유닛(PE: Processing Element)을 2차원 격자로 물리 배치합니다:

```
            입력 피처맵 (Pattern) ──►
                 ↓        ↓        ↓
가중치 필터 ──► [ PE ] ──► [ PE ] ──► [ PE ]
                 ↓        ↓        ↓
가중치 필터 ──► [ PE ] ──► [ PE ] ──► [ PE ]
                 ↓        ↓        ↓
가중치 필터 ──► [ PE ] ──► [ PE ] ──► [ PE ]
                 ↓        ↓        ↓
            누적 결과 출력 (Output)
```

- 데이터가 심장 박동(Systole)처럼 인접한 PE로 흘러가며 연산과 데이터 전달이 동시에 일어납니다.
- 메모리(DRAM) 접근 횟수를 획기적으로 줄이고, $N^2$개의 연산을 사실상 **단일 클럭 사이클(Clock Cycle)**에 병렬 처리함으로써 초저전력 초고속 AI 추론을 가능하게 합니다.
