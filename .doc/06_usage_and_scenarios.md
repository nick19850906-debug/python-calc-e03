## 2. 모드별 상세 실행 시나리오

### 2.1 [모드 1] 3×3 대화형 사용자 입력 모드 (`1` 선택)

사용자가 3×3 필터 A, 필터 B, 그리고 테스트할 패턴 데이터를 콘솔에서 직접 행 단위(3줄)로 입력합니다.

#### 1) 정상 입력 시나리오 예시
```text
#----------------------------------------
# [1] 필터 입력
#----------------------------------------

필터 A (3줄 입력, 각 줄에 숫자 3개를 공백으로 구분)
[1/3 행] > 0 1 0
[2/3 행] > 1 1 1
[3/3 행] > 0 1 0

필터 B (3줄 입력, 각 줄에 숫자 3개를 공백으로 구분)
[1/3 행] > 1 0 1
[2/3 행] > 0 1 0
[3/3 행] > 1 0 1

#----------------------------------------
# [2] 패턴 입력
#----------------------------------------

패턴 (3줄 입력, 각 줄에 숫자 3개를 공백으로 구분)
[1/3 행] > 0 1 0
[2/3 행] > 1 1 1
[3/3 행] > 0 1 0

#----------------------------------------
# [3] MAC 결과
#----------------------------------------
A 점수: 5.000000
B 점수: 1.000000
연산 시간(평균/10회): 0.0022 ms
판정: A (A 점수 우세 (차이: 4.0000))
#----------------------------------------
```

#### 2) 입력 오류 및 자동 재입력 복구 시나리오
- **열 개수 부족 오류**: `[1/3 행] > 1 0` (2개만 입력)
  - `입력 형식 오류: 각 줄에 3개의 숫자를 공백으로 구분해 입력하세요. (입력 개수: 2)` 출력 후 해당 필터의 1행부터 다시 입력을 유도합니다.
- **문자/특수문자 입력 오류**: `[2/3 행] > 1 a 0`
  - `입력 형식 오류: 숫자(정수 또는 실수)만 입력 가능합니다.` 출력 후 안전하게 재입력으로 복구됩니다.

### 2.3 [모드 3] 2D vs 1D 최적화 벤치마크 (`3` 선택)

$3 \times 3$부터 $100 \times 100$ 크기까지 2D 리스트 인덱싱 방식과 1D Flattening 방식의 실행 시간을 100회 반복 측정하여 속도 향상비(Speedup)를 실측합니다.

```text
크기 (N×N)     연산 횟수(N²)    2D 방식 (ms)      1D 방식 (ms)      속도 향상비   
----------------------------------------------------------------------
3×3          9              0.00195          0.00098          1.99x     
5×5          25             0.00412          0.00210          1.96x     
13×13        169            0.02210          0.01250          1.77x     
25×25        625            0.07980          0.04890          1.63x     
50×50        2500           0.31200          0.19800          1.58x     
100×100      10000          1.24500          0.81200          1.53x     
----------------------------------------------------------------------
※ 1D Flattening 방식은 2단계 인덱싱 오버헤드를 줄여 캐시 효율과 연산 속도를 개선합니다.
```

### 2.4 [모드 4] 패턴 자동 생성기 (`4` 선택)

임의의 격자 크기 $N$을 입력하면 완벽한 대칭 구조의 Cross 또는 X 패턴 격자를 콘솔에 시각화하여 생성해 줍니다.

```text
생성할 격자 크기 N (홀수 권장, 종료는 0) > 5
생성할 패턴 타입 (1: Cross, 2: X) [기본: 1] > 2

--- 생성된 5×5 X 패턴 ---
1 0 0 0 1
0 1 0 1 0
0 0 1 0 0
0 1 0 1 0
1 0 0 0 1
```
